# 第四层：预测一个具体的人

[返回导读](README.md) · 上一篇：[认知、情绪与情境](03-cognition-emotion-situation.md)

这一篇不增加新的机制。它把前三篇收成学习时能用的判断：对一个具体的人，什么比较能预测，什么不能，以及若目标是准确，一份人物描述必须让读者回答哪些问题。例子仍然是：这个人会不会用一个应用，会不会为它付钱。这里不讨论怎样把这些问题写成软件、提示词或数据表。那是另一件事。准确首先是一个证据问题。

读的时候请随时翻回相应的一层。每条结论后面标了它站在哪一篇上。没有标成「已测量的效应量」的句子，就是框架性的推论，不是新的实验。

## 没有统一的第一因素

不能负责任地写出「性格占四成、情境占六成」这类对所有决定都成立的分解。[Funder（2006，2009）](03-cognition-emotion-situation.md) 已经说明，人与情境哪边方差更大不是一个好问题。行为是人与情境的函数。不同的预测对象，函数里醒目的项不同。

可以把范围缩小到「会不会用、会不会付钱」，然后按条件说谁更能动这一次。

当题目的表述明确、得失被编成收益或损失、当事人没有余地慢慢覆盖默认反应时，框架本身就会移动选择。这是前景理论和框架研究的直接内容（Kahneman 与 Tversky，1979；Tversky 与 Kahneman，1981）。效应系统，但不是人人都中。所以框架是强因素，不是开关。

当决定当下的感受和冷静的概率评估不一致时，行为常常跟着感受走（Loewenstein、Weber、Hsee 与 Welch，2001）。情绪还可以从一件无关的事渗进这次估值（Phelps、Lempert 与 Sokol-Hessner，2014；Lerner、Li、Valdesolo 与 Kassam，2015）。这时「他是一个理性比较功能的人」会输给「他现在觉得这笔钱危险」。

当问题是公平、合作或拒绝一笔不敬的分配时，群体日常的回报结构可以大过年龄、性别和财富（Henrich 等，2001）。个体差异当然还在，只是在那项研究里，个人人口学变量没有稳健地解释博弈行为。

当要预测的不是这一次，而是一类行为的趋势——会不会一再守约、会不会在许多场合都把事情做完——特质的信号变大。Ozer 与 Benet-Martínez（2006）表明人格与有后果的生活结果相连。McAdams 与 Pals（2006）总结既有文献：特质对单次情境往往只是中等预测，对汇总后的行为趋势好得多。等级顺序在成年后相当稳（Roberts 与 DelVecchio，2000），所以趋势不是一句空话。它仍然不是单次付款的开关。

当环境有稳定线索，而且这个人得到过重复反馈，他的快速判断可以是技能；否则自信没有证明力（Kahneman 与 Klein，2009）。应用商店里的一次冲动点击，多数更像后一种。一个反复采购同类工具的人，才可能是前一种。

生物学不与上面各项比赛百分比。它规定哪些预测不能合并：[想要、喜欢、习惯、目标导向的重算](01-biology-and-evolution.md) 是不同的结果。一个人可以想要试用，不喜欢使用，仍因习惯打开，或在价格进入价值信号之后拒绝付钱。把这四者预测成同一个「会用」，是机制上的错误，不管人格档案写得多细。

## 什么比较可预测

可预测，在这里意思是：若你拥有下面说的那类信息，文献表明信号是存在的。它不是说你已经拥有这些信息，也不是说误差会很小。

相对位置比绝对形容词可预测。成年之后，谁比同龄人更尽责、更情绪稳定，过几年仍有相当的等级顺序，而且中老年高于青年（Roberts 与 DelVecchio，2000）。「他挺靠谱」没有这种测量含义。「他在尽责性上高于和他同类的人」才有。平均水平还会随生命阶段移动（Roberts、Walton 与 Viechtbauer，2006），所以相对位置也要带上大约的年龄段。

重复出现的情境里的行为趋势，比一次实验室式的动作可预测。这是 McAdams 与 Pals 从 Epstein（1979）一脉文献里抽出的教训，也是 Mischel 与 Shoda（1995）的正面主张：若—则签名本身可重复。你若见过这个人在「需要现在绑卡」和「可以先试用、卡先不绑」两类情境里分别怎么做，你拥有的是签名，而不只是一个特质分数。

群体水平的经济生活模式，比一张人口学表格更能预测公平和合作类行为，至少在 Henrich 等人（2001）的博弈里是这样。日常里合作有回报的地方，实验里的合作更高。付费、退款、是否觉得「占便宜可耻」，更接近这类行为，而不是接近果汁选择。

在高规律、有反馈的环境里，练出来的再认可预测当事人的专业判断（Kahneman 与 Klein，2009）。这只覆盖他真正练过的那类决定。

结构化的信息、用一致的规则合并，往往至少不差于、并且平均略优于临床式的整体印象。Grove、Zald、Lebow、Snitz 与 Nelson（2000）元分析了健康与行为领域里临床预测和机械预测的比较。平均而言，机械预测大约比临床预测更准确 10%（他们的表述是 about 10% more accurate）。这里保持他们自己的说法，不把它换算成百分点。视具体分析而定，机械方法明显更好的研究占 33% 到 47%；临床方法明显更好的只有 6% 到 16%。大约一半的研究里两者差不多。临床判断在使用了访谈资料时相对更差。优势不取决于裁判的经验年限。

这条对学习预测的含义是方法上的，不是软件规格。丰富的故事印象，包括一次很长的访谈，并不自动比少数几个相关变量的一致合并更准。访谈甚至可能让人更差。人物写得生动，不是准确的证据。

## 什么不可预测，或只能很弱地预测

从一串性格形容词预测一次二元选择，超出了特质研究自己的声称。第二篇已经把限度写清楚。形容词甚至可能不是特质，而是日常「性格」的混合物，里面夹着目标和叙事。

从进化故事预测谁会订阅，没有被 [第一篇](01-biology-and-evolution.md) 的证据许可。Hamilton（1964）和 Trivers（1971）给出的是亲缘和互惠的条件，不是应用商店的偏好。Gould 与 Lewontin（1979）说明，当前看起来有用的故事不是起源证据。Henrich 等人表明，连公平出价都不是一个物种常数。

从当事人的事后解释反推过程，会系统性地采到他的常识理论，采不到不显眼的原因（Nisbett 与 Wilson，1977）。「我是因为好用才付钱的」可能真，也可能只是好用这个理由显眼。它不能单独充当机制证据。

在低效度环境里用「我了解这种人」的直觉，不符合 Kahneman 与 Klein 的边界条件。主观信心在那里无效。Tetlock（2005）在政治预测这个难领域里得到了同类教训：专家身份和敢下判断，并不等于预报准。他用伯林的比喻区分狐狸和刺猬。狐狸知道许多小事，能从多种传统里取用，事件变了就改；刺猬知道一件大事，守着一个传统，把公式套到含混的问题上。在他的记分里，狐狸的校准和分辨优于刺猬。媒体喜欢的那种单一、坚决的解释风格，和较好的判断指标是拧着的。本文打开的是他 2005 年书的论证结构，没有引用具体的准确率分数，那些数字需要按他的记分规则整表来读，不能抽一句百分比。

政治预报不是付费预测。可迁移的只有方法：用一个大理论（「内向的人都不付钱」「损失厌恶所以没人订阅」）覆盖所有人，是刺猬式的；按这个人的目标、这个题目的框架、这个领域的学习史分别更新，更接近他发现更准的那种思维方式。两种都不保证单次命中。

一次延迟满足，预测不了一个人后来的成就或行为纪律。Watts、Duncan 与 Quan（2018）在母亲未完成大学学业的儿童样本里，把早期等待和 15 岁成就之间的关联缩小到了控制背景之后所剩很少的程度。把一次「他等得住」写成「他会长期付费」，是把未测量的家庭资源和情境再讲述一遍。

最后，即使信息结构化、规则一致，行为仍然不是被决定的。Grove 等人的元分析里，机械方法平均大约只比临床判断更准确 10%，而且在大约一半的研究里两者差不多。更好，不是接近全知。低规律环境里，有效线索本身可能不存在，于是不存在可学习的准确直觉。一份把某人写成「一定会付钱」的人物描述，比一份写出残余不确定性的描述更不科学。

## 若目标是准确，人物描述必须能回答的问题

下面不是字段设计。它是一份学习用的核对表：读完对一个人的描述之后，你是否已经能回答。若答不出，前三篇的证据表示，这次预测所依赖的信息还缺着。缺的那一项，往往就是这次最能动选择的那一项。

**这个决定在他面前长什么样。** 选项是什么，参照点是什么，结果被说成收益还是损失，哪些部分被单独拿出来比较（Kahneman 与 Tversky，1979；Tversky 与 Kahneman，1981）。「应用很好用，定价 30 元」还没有回答这些。30 元相对什么，试用结束时他看见的句子是什么，不付会失去什么他已经觉得属于自己的东西，都还未知。

**他在相关维度上的相对位置，以及他的若—则签名。** 宽特质给出基线和生活趋势（Roberts 与 DelVecchio，2000；Ozer 与 Benet-Martínez，2006）。签名给出这个人如何随情境变（Mischel 与 Shoda，1995）。若决定涉及占便宜或公平，要意识到五因素可能没盖住诚实—谦逊（Ashton 与 Lee，2007），同时不要把该维度写成已经证明的付费预测。年龄段不能省，因为均值在变（Roberts、Walton 与 Viechtbauer，2006）。

**他在这个领域学到了什么。** 相近的工具、扣款、试用和退款，结果比他的预期更好还是更差（Schultz、Dayan 与 Montague，1997）。那些结果更像留下了习惯，还是他还在按后果重算（Daw、Niv 与 Dayan，2005）。没有这段历史，特质相同的两个人不该被预测成同样的付费行为。

**目标和自我叙事里，哪些选项会变成「不像我」。** 这是 McAdams 与 Pals（2006）的特征性适应和人生叙事。它回答的是：有些选项是否在进入价值比较之前就被身份排除。当事人宣称的理由要另标为自我理论，用行为核对（Nisbett 与 Wilson，1977）。

**这一次的情绪和身体状态。** 偶然情绪和对价格、风险的感受，可以调制甚至压过认知评估（Loewenstein 等，2001；Phelps 等，2014；Lerner 等，2015）。特质水平的情绪稳定性代替不了这次的状态。自控则要问长期考虑有没有写进同一次价值，而不是他有没有一种抽象的意志（Hare、Camerer 与 Rangel，2009）。

**他周围的人怎样对待这类交换。** 日常合作有没有回报，市场式的往来密不密，比年龄和收入更接近 Henrich 等人（2001）找到的那种群体差异。朋友是否把订阅当成正常开销，他是否处在一个拒绝小便宜会被看成傻的环境里，都属于情境，而不是性格的注脚（Funder，2006）。

**你准备预测的是一次，还是一串。** 一次安装、一次付款，残余误差大，情境和框架的权重高。一串行为——会不会留下、会不会在提醒之后取消、会不会向别人推荐——才是特质和签名更能发力的对象。把一次的预测写成性格因果，是这套文献里最常见的越级。

**你是否把生动当成了准确。** Grove 等人（2000）和 Tetlock（2005）从两个领域说明同一点：经验丰富的整体判断、以及又完整又坚决的故事，都不是准确的保证。狐狸式的做法是保留多个小事实，并允许它们互相修正。人物描述若只能引出一个形容词，它还没有开始预测。

## 一个贯穿的例子

假设要判断某人会不会为一个记录习惯的应用付年费。按层走一遍，看信息分别消灭哪种错误。

生物层禁止把「他说自己喜欢这个点子」写成「他会付钱」。喜欢、想要、习惯和把年费写进价值，是四次不同的计算。进化层禁止补一句「人天生要追踪地位，所以他会买」。这是拱肩式的故事。

人格层允许一个弱的、关于趋势的判断。若他在尽责性上稳定地高于同龄人，他更可能把一类需要坚持的活动做下去；这是生活结果文献的方向，不是这次付款的概率。还要问他的签名：在「先免费、以后再说」时他是否几乎总是开始，在「一次付清全年」时他是否几乎总是停。身份层问年费会不会把他写成自己故事里浪费的人。

情境层往往决定这一次。年费是被说成「每天不到一杯茶」，还是「又一张不能退的账单」。他是不是刚被另一个订阅激怒。他的朋友是不是都在用、不用就显得懒。这些都不在人格分数里，却在前景理论、风险即感受和群体回报的证据里。

若这些都未知，诚实的学习结论是：你还不能预测这个人。你最多能预测一个很薄的类型在平均框架下的平均趋势，并且应该预期自己经常错。这不是谦虚的套话。它是 Grove 等人所记录的预测上限、Kahneman 与 Klein 所记录的环境条件，以及特质研究自己对单次行为的保留。

## 这一层如何改变一次预测

综合层不增加杠杆，它防止用错杠杆。

先声明预测对象是一次行为还是一串趋势。再把题目的框架、当下情绪、领域学习史和群体回报放在特质旁边，而不是放在注释里。把想要和喜欢分开。把当事人的理由标成需要核对的理论。拒绝进化轶事和单点性格实验的终身外推。用一致的方式合并你真正有的变量，同时保留残余误差。生动的人设若答不出上面那张问题表，它对准确没有贡献，不管它多像一个真人。
