## 第一章 生物机制与进化

| 术语 | 本书里的意思 |
| --- | --- |
| 基于价值的选择 | 在几个行动之间比较「这对我有多值」再选一个；包括表征问题、赋值、选择、评估结果、更新五类计算 |
| 估值 | 给一个行动打分。不同学习系统各自打分，风险、时间、社会因素会调高或调低 |
| 共同尺度 | 比较时把不同方面收成可以放在一起比的量；不等于每次都选得前后一致 |
| 奖赏预测误差 | 结果比预期好或坏的那个差值；用来更新下一次的预期，不是快乐本身 |
| 想要（wanting） | 线索让人想去追的那股劲；激励显著性 |
| 喜欢（liking） | 使用时的享乐反应；可以和想要分开 |
| 习惯系统 | 用过去缓存的价值快速再选；便宜但世界一变就僵 |
| 目标导向系统 | 用对后果的模型当场重算；灵活但费计算 |
| 自控（本书用法） | 长期考虑有没有写进同一次估值；不是一份意志力库存 |
| 偶然情绪 | 不是由眼前选项引起、却带进这次估值的心情 |
| 内含适合度 | 行为对自己后代的影响，加上对亲属的影响按亲缘远近打折 |
| 互惠利他 | 因为以后能换回帮助而先帮非亲属；需要时间差和防作弊 |
| 适应主义纲领（被批评的） | 给每个性状单独编一个适应故事，用合理性代替证据 |

## 第二章 人格、性格与经历

| 术语 | 本书里的意思 |
| --- | --- |
| 人格 | 人格心理学试图测量的整个人（McAdams 与 Pals 的五条原则） |
| 特质 | 在某个宽维度上相对别人的位置 |
| 特征性适应 | 目标、策略、动机、价值观、解释习惯；比特质更靠近具体情境 |
| 人生叙事 / 身份 | 把生活讲成可理解的故事；会让某些选项因为「不像我」退出比较 |
| 性格（日常用法） | 特质、适应、叙事的混合物，常带评价；不是一个科学维度 |
| 大五 / HEXACO | 五个或六个宽人格维度；HEXACO 多一条诚实—谦逊 |
| 等级顺序一致性 | 同龄人之间谁高谁低，过几年还像不像原来的排列 |
| 平均水平变化 | 整个队列在某个特质上的均值随年龄怎么走 |
| 若—则签名 | 「若情境 A 则做 X，若情境 B 则做 Y」这种可重复的变化模式 |

## 第三章 认知、情绪与情境

| 术语 | 本书里的意思 |
| --- | --- |
| 有限理性 | 算力有限，问题先被简化；不假定做了全局最优 |
| 参照点 | 区分收益和损失的那个零点 |
| 编辑 | 估值之前先把问题改写成某种表征 |
| 确定性效应 | 相对于可能的结果，对确定的结果赋予过高权重 |
| 孤立效应 | 丢掉各选项共有的部分，只比较差异 |
| 框架 | 对行动、偶然性和结果的表述；能移动偏好，但不是人人都中的开关 |
| 启发式（窄定义） | 忽略一部分信息的认知过程；好不好取决于环境 |
| 直觉（再认） | 线索被认出，答案随之出现；需要有效线索和重复反馈 |
| 类型 1 / 类型 2 过程 | 自主迅速的默认反应 / 占用工作记忆、能做假设性思考的过程 |
| 评价倾向 | 一种情绪带着自己的评价方式去看情境，把判断推向某个方向 |
| 风险即感受 | 认知评估和当下感受分叉时，行为常常跟着感受走 |
| 人格三角 | 人、情境、行为，每个都要用另外两个来理解 |
| 自我理论（本书用法） | 当事人事后说的理由；来自常识理论，不是对过程的观察 |

## 第四章 预测一个具体的人

| 术语 | 本书里的意思 |
| --- | --- |
| 一次行为 / 一串行为 | 今天会不会付这一笔 / 未来一段时间会不会持续付；不是同一个预测对象 |
| 临床预测 | 判断者凭整体印象在脑子里综合信息 |
| 机械预测 | 用一致的规则合并变量 |
| 狐狸 / 刺猬 | 从多种来源取用并随事件修正 / 守着一个大理论套到所有问题上 |
| 校准 | 说的概率和实际发生的频率对得上不对得上 |
| 分辨 | 能不能把后来发生的和没发生的分开 |

## 第五章 从说到做

| 术语 | 本书里的意思 |
| --- | --- |
| 意图—行为缺口 | 打算做和真的做之间的差距；主要来自想做没做的人 |
| 有意未行者（inclined abstainers） | 表示有意图却没有行动的人 |
| 陈述偏好 / 显示偏好 | 嘴上说愿意付多少 / 真实花了多少 |
| 假设性偏差 | 陈述偏好高于显示偏好的那部分；分布右偏，没有固定倍数 |
| 比较式问法（相对 monadic） | 在几个选项之间选 / 单独评一个产品 |
| 对未来自己的过度自信 | 选合同时高估自己将来的使用量和取消的可能性 |
| 默认 | 什么都不做时的结果；改变它要付出成本 |

## 第六章 怎样知道预测准不准

| 术语 | 本书里的意思 |
| --- | --- |
| 内部视角 / 外部视角 | 盯着这件事的计划和情节 / 先看一类相似事情的结局分布 |
| 参照类 | 在相关方面和眼前这件事相似的一类事情 |
| 基础率 | 参照类里某个结局通常出现的比例；预测的起点 |
| 布里尔分数 | 概率减去结果（1 或 0）后平方再取平均；越低越好，永远说 50% 得 0.25 |
| 群体智慧 | 很多独立估计合起来误差互相抵消；前提是独立 |
| 不恰当的线性模型 | 权重不是统计最优、甚至全部相等的加权和；常常已胜过直觉 |
| 可预测性上限 | 即使数据丰富、方法优化，对个人结果的预测也可能只比简单基准好一点 |

## 第七章 让语言模型扮演人

| 术语 | 本书里的意思 |
| --- | --- |
| 算法保真度 | 模型在恰当条件下模仿特定人群回答分布的程度 |
| 硅样本 | 用人口学背景设定模型生成的模拟样本 |
| 图灵实验 | 用模型模拟一个有代表性的被试样本，看能否复现已有发现 |
| 失真（相对偏差） | 模型与人之间系统性的差异，区别于人和机器都可能有的偏差 |
| 错误刻画 | 扮演某身份时说出外人以为这群人会说的话 |
| 群体扁平化 | 抹去群体内部的差异 |
| 顺序 / 标签偏差 | 回答受选项位置和字母影响，例如偏爱「A」 |
| 超准确失真 | 扮演普通人时却给出完全正确的冷门答案 |
| 归一化准确度（Park 等） | 代理预测某人回答的准确度，除以本人两周后重答的一致性 |
