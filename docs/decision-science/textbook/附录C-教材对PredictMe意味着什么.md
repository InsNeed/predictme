# 附录 C 教材对 Predict Me 意味着什么

[返回课本首页](README.md)

正文七章是学习材料，不规定产品怎么做。这份附录是桥：把正文的结论，对照到 Predict Me 第一版（见 [PRD](../../predictme-prd.md) 和 [V1 缺口](../../v1-gaps.md)）的做法上，列出教材会追问的问题。

这里每一条都是推论，不是实验结论，也不是需求。它们说明的是：若目标是决策准确率，教材认为哪些地方还缺证据，以及缺的是哪一类证据。改不改、怎么改，是产品决定。

## 一、现在这套系统预测的到底是什么

按 [第五章](05-从说到做.md) 和 [第七章](07-让语言模型扮演人.md) 的区分，DeepSeek 扮演一个人设、回答「会用 / 会付钱」，得到的是：一个模型对「这类人被这样问时会怎么说」的估计。它至少隔着三层才到「这个人真的会不会付钱」：

1. 模型和这类真人之间：回答更集中、更像外人眼里的群体、受措辞和选项顺序影响（第七章）。
2. 这类真人和这个具体的人之间：人设是按权重生成的，不是某个真实的人（第二章到第四章）。
3. 说和做之间：意图有方向性缺口，假设性支付通常高估（第五章）。

所以界面上的「会付钱 2/3」，在教材的语言里是「三个模拟人设里有两个被模型判为会付钱」，不是付费率，也不是付费意愿的人群估计。PRD 已经写了「不把 3 个人的比例说成全国比例」；教材补充的是：即使实呼 960 人，它仍然不是付费率，因为第三层的缺口没有被任何数据缩短。

## 二、教材会追问的十个问题

**1. 参照类和基础率在哪里？**（[第六章](06-怎样知道预测准不准.md)）现在每个人设从零开始判断。教材要求先有一个起点：同类应用、同类人群，最后真的用了、真的付了的比例。没有这个数，预测的起点是凭空的。这个数需要外部数据，教材本身不提供。

**2. 输出能不能被打分？**（第六章）现在是 `primary_yes` / `secondary_yes` 两个布尔值。是或否只能判对错，不能算校准和布里尔分数。若改为概率，并在事后对照真实结果，才谈得上「准确率」。

**3. 有没有外部对照？**（第六章）V1 缺口已经写了「没有外部对照，谈不上准确率」。教材的说法更直接：只能说「模型的回答和设定一致」时，报告的是一致性，不是准确性。最小的外部对照，是对一个已经上线、知道真实下载和付费数据的应用跑一次预测，再比较。

**4. 被问的问题落在意向容易还是难预测购买的一侧？**（第五章）「会不会为这个新应用付钱」几乎在 Morwitz 等人（2007）的每一条上都落在难的一侧：新产品、时间窗模糊、单独问一个产品。若问题能改写成「下周会不会试用它，而不是你现在用的那个」，就有几条换到容易的一侧。

**5. 付钱是不是被拆开了？**（第五章）第一笔、使用、续费、取消是四个预测对象。默认值是什么（试用到期自动扣款还是自动停止）会直接改变「付没付」的结果。用户的原话里若没有这些信息，人设的判断是在一个没写清的问题上做的。

**6. 人设里有没有关于这个人的真实资料？**（第七章）现在的人设由人口学权重和分配的特质、情境组成。Park 等人的结果显示，只用人口学信息的代理在他们的比较里最弱；有真实访谈或问卷的代理明显更好。Predict Me 的人设不是真实个人，这一层差距是结构性的。

**7. 情境条件的分布是测到的吗？**（第六章、第七章）V1 缺口已经写明：学习史、框架、情绪、群体回报是均匀摊开的，不是测到的流行率。教材补充：均匀摊开会让「被自动续费伤害过的人」和「没被伤害过的人」各占相近的份额，这本身就会移动汇总结果。汇总结果因此部分反映了分配规则，而不是人群。

**8. 选项和示例会不会被当成意见？**（第七章）用户提示里的 JSON 示例把两个判断都预填成 `false`。Dominguez-Olmedo 等人（2024）显示模型的回答会受选项顺序和标签影响。一个直接的检查是：把示例值反过来，或者正反各问一次，看结果变不变。变了，变化的那部分就不是人设的意见。

**9. 多个人设的回答独立吗？**（第六章、第七章）所有人设由同一个模型、同一套系统提示生成。Lorenz 等人（2011）说明，不独立的判断合并起来得不到群体智慧的好处，一致也不说明对。多个人设「都说不会」，可能只是同一个模型的同一个倾向。

**10. 模型扮演的人知道得是不是太多？**（第七章、第三章）人设拿到的是用户写的完整描述。真实的人可能只看过一眼应用商店的截图。Aher 等人（2023）的超准确失真提醒：一个比真人知道得多的人设，预测的是一个不存在的消费者。

## 三、哪些人群的预测要额外小心

第七章的研究几乎都用美国人群。本书没有打开研究中文模型模拟中国人群的论文，所以不知道 DeepSeek 对哪些中国人群反映得好、哪些反映得差。已有证据能说的只是：

- 模型的偏差随人群变化，不是一个统一的倾向（Argyle 等，2023）。
- 在美国数据里，年长者等群体被反映得尤其差，引导也消除不了（Santurkar 等，2023）。
- 身份相关的问题上，模型更像外人眼里的群体（Wang 等，2025）。

Predict Me 的抽样框是 15–74 岁、按城乡铺开。对于农村、年长、低收入这些在网络文本里自述较少的人群，教材会要求把不确定性写得更大，而不是更小。这一条是推论，不是对 DeepSeek 的测量。

## 四、教材支持什么样的用法

把正文的限制合起来，教材支持的定位是：Predict Me 是一个**提出假设、检查问题有没有问清楚**的工具，而不是一个**给出付费率**的工具。具体说：

- 它能帮用户看见一个决定被拆开后的样子：预期、想要、喜欢、习惯、框架、默认、续费，分别可能指向哪里（第一章到第五章）。
- 它能暴露问题本身的缺口：参照点没写、默认没写、时间窗没写、问的是一次还是一串（第三章到第五章）。
- 它给出的比例，最多是在同一套设定下比较两个版本的问题（例如两种定价说法）时的相对信号，并且要在换措辞、换选项顺序、换时间之后仍然站得住（第七章）。
- 它的准确率，只能在拿到真实结果之后、在一组预测上算出来（第六章）。

教材不支持的用法是：把模拟人设的「会付钱」比例当成转化率、拿来定价或拿来向别人证明市场存在。Brand 等人的修订版结论正好落在这里：模型可以补充，不能替代人类研究；没有同类真实数据去校正时，它的支付意愿估计常常不准，有时方向相反。
