# 人如何做决定：给 Talia 的课本

这本书给 Talia。Predict Me 要预测的不是「一般人会不会喜欢一个点子」，而是一个具体的人会如何做决定。典型问题始终是两句：这个人会不会用这个应用，会不会为它付钱。

课本只回答一个学习问题：这样的预测，在科学上站在哪些层次上；每一层真正推动的是什么；哪一层只是看起来像解释。它不教你写提示词，不教你存人设，不教你调模型，也不规定界面和数据该怎么做。那些不是这门课。

材料用简体中文写成。文献保持原文题名，方便回查。正文里的链接，只放在撰写原始笔记时实际打开过的来源上。没有链接的条目，仍然核对过作者、年份和题名。课本不新造论文、作者、年份、引文或统计数字。文中标成「例子」的段落，是为了把概念说具体，不是研究结果。

## 怎样最快读到深处

层次是从下往上叠的。下面一层约束上面一层，但不能代替上面一层。另外把两个预测对象分开：一次行为（今天会不会安装、会不会付这一笔），和一串行为（会不会留下来、会不会一再守约、未来一段时间会不会持续付钱）。一次会不会付钱，和这个人未来一年会不会持续付钱，本来就不是同一个预测对象。

比较省力、又不把深度丢掉的顺序是：

1. 读完本页。记住「层」，记住「一次行为 / 一串行为」。
2. 读 [第一章 生物机制与进化](01-生物机制与进化.md)。先拆掉两个常见误会：多巴胺等于快乐；一个进化故事就等于这个人会付钱。
3. 读 [第二章 人格、性格与经历](02-人格性格与经历.md)。看特质有多稳。它稳的是人与人的排序，以及跨场合汇总起来的趋势，不是每一次选择。
4. 读 [第三章 认知、情绪与情境](03-认知情绪与情境.md)。看同一位当事人为什么会在两种说法、两种心情、两种社会环境里做出不同选择。
5. 最后读 [第四章 预测一个具体的人](04-预测一个具体的人.md)。用前面的限制来问：这份对一个人的描述，够不够支撑一次准确的预测。

如果时间很少，也不要只读第四章。第四章里的每条结论都指回前面的证据。可以先读各章结尾的「这一层如何改变一次预测」，再回头读自己还说不清的论证。

每个难懂的概念，按下面六步读完再往下走：

1. **一句话。** 这个概念本身是什么。
2. **大白话。** 不靠术语，把它说成一件能复述的事。术语在第一次出现时会解释。
3. **例子。** 同一个人、同一个选择：林可会不会用一个记录习惯的应用，会不会为它付钱。例子短，并且对准刚才那个概念。例子不是实验。
4. **文献里的准确说法。** 作者、年份、题名和原有限定都留在这里。
5. **常见误会。** 包括原始笔记故意不采用的说法，以及文献内部还没解决的分歧。
6. **这如何改变对「这个人会怎么选」的预测。** 这一步只使用前面已经写下的证据，不另加一条科学结论。

读完一章，停下来用自己的话回答三句：这里什么是已经测到的；什么仍有争议；一份很薄的性格素描为什么还不能预测这一次。能答上，再进入下一章。

## 贯穿全书的同一个人

例子里的人叫林可。她在看一个记录习惯的应用：每天勾选自己有没有做到一件小事。问题永远是：她会不会用它，会不会为它付钱。付钱在不同段落里会换成试用、一次买断、每月扣款，或一次付清全年，以便对准那个概念。林可不是被试，不是案例研究，文中也不把她的选择写成测量结果。

## 四章各自讲什么

| 章节 | 这一层 | 它让你看见什么 |
| --- | --- | --- |
| [第一章 生物机制与进化](01-生物机制与进化.md) | 选择如何被神经系统实现；这些倾向为什么可能在进化上存在 | 估值、奖赏学习、「想要」和「喜欢」不是一回事；进化解释有证据强弱之分 |
| [第二章 人格、性格与经历](02-人格性格与经历.md) | 人与人之间相对稳定的差异，以及这些差异从何而来、稳到什么程度 | 特质、日常所说的性格、目标与自我叙事不是同一个东西；它们对一次决定和对一串行为的预测力不同 |
| [第三章 认知、情绪与情境](03-认知情绪与情境.md) | 一次具体决定被当场改写的那些力量 | 有限认知、启发式争论、情绪、框架和社会情境；人与情境不是二选一 |
| [第四章 预测一个具体的人](04-预测一个具体的人.md) | 把前三层收成学习结论 | 什么比较可预测，什么不可预测；若目标是准确，一份人物描述必须能回答哪些问题 |

第四章是学习上的综合，不是产品规格，也不是模型或人设的实现说明。它不增加新的机制。

## 这套材料不解释什么

它不解释怎样写提示词、怎样存储人设、怎样调用模型，也不解释界面或数据该怎么做。那些不属于这门课。

它也不提供一份「影响决策的因素排行榜」。没有一篇可靠的文献支持「性格占百分之多少、情绪占百分之多少」这种对所有决定都成立的分解。一次会不会付钱，和这个人未来一年会不会持续付钱，本来就不是同一个预测对象。

它不教如何操纵别人做决定。框架、情绪和社会压力会出现，因为它们改变选择；这里只把它们当作预测时必须知道的条件。

它不下临床诊断，不讨论自由意志的哲学结论，也不把脑成像当成可以读出陌生人购买意愿的仪器。

## 怎样对待文中的判断

每章都把证据分成两类。一类是实验、元分析或正式模型直接支持的发现。另一类是研究者提出的解释，同行并不同意，或者只是听起来合理。进化心理学里很多关于现代消费行为的故事属于第二类。本文要么不写，要么标明它是推测。

数字只在打开过的摘要、表格或正文里出现过才写入。棉花糖实验、人格稳定性、机械预测与临床预测这几处的数字都带样本条件和原作者的限定，不能抽出来当成普遍定律。

## 因为无法核对而故意不写的说法

下面这些话常出现在通俗文章里。撰写时没有找到可以核对的原始出处，或者只找到与它们相反的证据，因此没有写进正文，也不要在学习时把它们补回去。

- 「百分之九十五的决定是无意识做的」，以及任何把无意识决策写成精确百分比的句子。
- 「多巴胺就是快乐物质」。奖赏研究内部对多巴胺的功能有明确分歧，见第一篇。
- 损失厌恶的某个固定系数（例如 2.25）。1979 年的前景理论只支持「损失一侧通常比收益一侧更陡」，本文没有核对后来那次参数估计的原文，所以不引用该数字。
- 「人格与行为的相关大约是 0.30」。这是人格争论里的著名说法，但本文没有核对 Mischel 1968 年原书的表述，故不用这个数字。第二篇改用已经核对过的稳定性元分析，以及 McAdams 与 Pals 对单次行为与行为趋势的区分。
- 「棉花糖实验能预测一个人的一生」。Watts、Duncan 与 Quan（2018）的概念性重复不支持这么强的说法，见第二篇。
- 「催产素是信任激素」，以及任何单一脑区是「购买按钮」的说法。
- 用进化模块直接解释谁会为一个应用付钱、谁在意地位、谁更不愿意付订阅费。这类故事没有在这里被证据托住。Gould 与 Lewontin（1979）说明了为什么「听起来适应」不够。
- 人格特质的遗传力百分比。行为遗传学有自己的文献，本文没有打开到可以负责地引用数字的程度。
- 「数字足迹比朋友更了解你」一类商业说法。相关论文没有在撰写时打开，故不引用。
- 政治预测比赛里的具体准确率分数。Tetlock（2005）只用来说明专业自信和准确不是一回事，以及思维方式上的差别，不引用未核对的分数。

若以后要补上其中任何一条，先打开原文，再决定它是发现、是争论，还是该继续留在这份清单里。

## 读完以后你应该能说出的话

你应该能分开说：什么已经有实验、元分析或正式模型支撑；什么是研究者的解释，同行还在争，或者只是听起来合理。你也应该能说出：一份只有形容词的人物素描，预测的是一个类型的平均趋势，不是这个人在这个框架、这种心情、这个群体里的这一次。
