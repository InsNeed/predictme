# 第三层：有限认知、情绪与情境

[返回导读](README.md) · 上一篇：[人格、性格与经历](02-personality-and-experience.md)

前两层容易让人以为：只要把脑的估值机器和人格档案写全，一次决定就定了。这一层的证据指向相反的方向。同一个人，问题的说法换一换，心情换一换，周围的人换一换，选择会系统性地变。这些变化不是人格测量的误差。它们是决定的一部分。

本篇不提供一份偏差清单。清单会让人以为每个人身上都装着同样几条故障，查出故障就能预测。真正的争论是：人偏离标准理性模型时，这算错误，还是算在不确定世界里够用的办法；直觉什么时候是本事，什么时候只是自信；情绪是干扰项还是价值的输入；人与情境哪一个「更重要」这个问法本身是否成立。

## 人不是在无限制下求最优

Simon（1955）批评当时的理性选择定义离真实的决策过程太远。他要构造的理性，是更贴近有机体实际做法的理性：计算能力有限，问题必须被简化，决策理论才可能既描述人，又在复杂组织里用得上。后来的文献把这条路线称为有限理性。本文打开的 1955 年文本强调的是「近似」的理性定义，而不是一份心理偏差目录。

这一点和 [第一篇](01-biology-and-evolution.md) 的计算分工是同一件事的两面。Daw、Niv 与 Dayan（2005）从脑的角度说：缓存的习惯便宜，使用世界模型的重算贵，系统按不确定性分配。Simon 从行为的角度说：不要假定当事人做了那个贵的、全局的最优。预测「他会不会付钱」时，若假定他读完了全部定价、比较了全部替代品、再最大化终身效用，这个假定本身就不符合有限理性传统。他更可能在一个被简化的问题里停下来：这个月能不能承受、是不是和上次那个糟糕的订阅一样、朋友有没有在用。

## 前景理论：价值是相对于参照点构造的

Kahneman 与 Tversky（1979）处理的是风险下的选择，而且是描述性理论，不是「人应该如何选择」。期望效用理论长期被当作理性规范，也被当作经济行为的描述。他们给出几类与该理论不一致的现象。其一是确定性效应：相对于仅仅可能的结果，人对确定能得到的结果赋予过高的权重。这使人在收益侧更回避风险（偏好确定的收益），在损失侧更寻求风险（不愿接受确定的损失）。其二是孤立效应：人会丢掉所有选项共有的部分，只比较差异。同一个选择用不同方式呈现，偏好可以不一致。

他们因此提出前景理论。价值定义在收益和损失上，而不是最终财富上。价值函数在收益侧通常凹，在损失侧通常凸，而且损失一侧一般比收益一侧更陡。概率被决策权重代替：权重总体低于相应概率，但低概率除外，低概率会被高估。编辑在前，评估在后。人先把问题改写成某种表征，再对这个表征估值。

对「会不会付钱」来说，理论的核心不是「人害怕损失」这句口号。核心是：他正在比较的收益和损失，取决于参照点和问题被如何编辑。每月 30 元可以是「少一杯咖啡」（小的损失，或从某个消费账户里的日常支出），也可以是「又一个永远扣下去的订阅」（没有终点的损失）。功能上的好处可以是「确定能省下的时间」，也可以是「有可能更方便」。确定性效应预言这两种编辑不会得到同一个选择。孤立效应则预言：若试用期被单独拿出来看，人会忽略试用结束之后两份合同共有的结构。

Tversky 与 Kahneman（1981）把框架效应讲成一个更广的现象：对行动、偶然性和结果的表述做看起来无关紧要的改动，会显著移动偏好。他们说这些效应大而且系统，但绝不是普遍的。后半句同样重要。不能从前景理论推出「只要改成损失框架，这个人就会拒绝」。理论描述的是常见的构造方式，以及它与期望效用的冲突。个体是否在这个题目上跟随框架，仍是经验问题。1981 年的文本还指出，框架有时会改变结果被体验的方式，而不只是改变描述。把一笔支出体验成纯损失，还是体验成为了换取好处而付的成本，感受可以不同。

所以预测者必须先写清题目，再写人。不写参照点的人设，是在预测一个没有被编辑过的决策问题。真实的人碰到的从来不是这种问题。

## 启发式：偏差，还是与环境相称的工具

1974 年，Tversky 与 Kahneman 的一篇《Science》论文后来被双方都当成「启发式与偏差」纲领的起点。Kahneman 与 Klein（2009）以及 Gigerenzer 与 Gaissmaier（2011）都这样追溯。本文没有重读 1974 年原文，下面关于该纲领的概括采用这两篇后来的综述：人依赖少数启发式，因而系统性地偏离逻辑或统计模型所规定的答案。Kahneman 在诺贝尔演讲里把这项工作说成是在给有限理性画地图，地图的内容是信念和选择如何偏离理性行动者模型（Gigerenzer 与 Gaissmaier 对 Kahneman，2003，的引述）。

Gigerenzer 与 Gaissmaier（2011）认为这张地图把启发式预先判成了误差。他们的定义很窄：启发式是有意识或无意识的认知过程，它忽略一部分信息。忽略信息可以省力。古典观点由此推论，启发式一定比「理性」模型更不准。他们认为这个推论只在理性模型的假设成立时才自动为真。很多真实决策里，那些假设不成立。启发式好不好，是经验问题，取决于环境。他们综述的形式模型表明：在可预测性低、样本小的时候，忽略一部分信息，可以比把所有信息加权求和更准确。个人和组织都会适应性的使用简单启发式。

这不是字面之争。若你相信前一种纲领，预测任务就是找出他会犯哪种偏差。若你相信后一种，预测任务就是问：这个环境里，忽略哪些信息是聪明的，他过去有没有学会这条启发式。两种纲领都接受 Simon 的有限性。它们分歧在于，偏离统计最优时默认叫不叫错误。

Kahneman 与 Klein（2009）把另一对看起来对立的传统放在一起：启发式与偏差，以及自然主义决策（Klein 一派，关注消防员、飞行员等专家在现场的直觉）。他们原先预期会吵起来，结果在边界条件上大体同意。真正的直觉技能需要两件事。环境必须提供足够有效的线索，规律性要高到可以学习。当事人必须有机会学会这些线索，通常意味着重复和反馈。主观上「我就是知道」并不是准确的证据。Simon 把直觉定义为再认：线索被认出，答案随之出现。象棋大师可以这样下棋，因为棋盘规律稳定，而且他们见过极多局面。在规律弱、反馈慢或误导的环境里，同样的自信只是过度自信。

付费决策落在这条边界的哪一侧，不能先验地回答。一个天天比较同类工具、买错过、也退过款的人，可能真的练出了再认：看到某种定价页就知道会后悔。一个几乎不买软件、只凭这次广告落地页感觉「专业」的人，处在低效度环境里，他的信心不能被当成准确。预测时把所有直觉都写成偏差，或都写成专业，都不符合 Kahneman 与 Klein 的共同结论。

## 双过程：有区分，但不是一套通俗的系统 1 / 系统 2

Evans 与 Stanovich（2013）面对的是对双过程理论的集中批评。批评者说：所谓两个系统属性清单互相不一致，证据不足，单过程理论也能解释数据。Gigerenzer 以及 Kruglanski 与 Gigerenzer 的批评被他们引在文首。Evans 与 Stanovich 承认，这些批评打中了许多流行写法。他们拒绝保卫一个笼统的、把一长串属性绑在「系统 1」和「系统 2」上的版本。

他们仍保卫一个较窄的区分。类型 1 过程自主、迅速，给出默认反应。类型 2 过程能够做假设性思考，并且大量占用工作记忆；它在默认反应出错或需要被覆盖时介入。区分的定义是工作记忆和假设性思维，不是「情绪对理性」，也不是「无意识占百分之多少」。后一种百分比没有可靠出处，[导读](README.md) 里已列为不写的说法。

和 [第一篇](01-biology-and-evolution.md) 放在一起读，会少一个误会。Phelps、Lempert 与 Sokol-Hessner（2014）反对的是「情绪系统对理性系统」的神经故事。Evans 与 Stanovich 保卫的是推理上的默认反应与工作记忆介入。两件事用同一对「系统 1 / 系统 2」来称呼，是通俗写作造成的合并。预测时更有用的问法是：这次他有没有动机和余地去覆盖默认反应。时间紧、信息被框架裁好、工作记忆被占用时，默认反应更可能直接成为选择。这仍然不是一个脑区的名字。

## 情绪：有规律的输入，不是噪声

Lerner、Li、Valdesolo 与 Kassam（2015）综述大约三十五年的情绪与决策研究。他们的总判断是：情绪是强烈的、普遍的、可预期的决策驱动因素，有时有害，有时有益。不同领域里，情绪影响判断的机制有规律，不是每个情绪只把人推向「不理性」。他们提出情绪浸入的选择模型，试图同时装下传统理性选择的输入和这些情绪发现。综述的关键词里包括评价倾向。本文用到的是这个层次：情绪通过它对情境的评价来影响判断，方向取决于是哪一种情绪，而不是取决于「他很情绪化」。具体哪一种评价对应哪一种风险偏好，需要回到他们引用的单项实验；这里不把未核对的对照表写成定律。

Loewenstein、Weber、Hsee 与 Welch（2001）补上时间尺度。认知评估可以说「这个订阅的期望值合算」，决定当下的焦虑、厌恶或不耐烦仍可以支配行为。他们称之为风险即感受。当两者分叉，行为常常跟着感受走。Phelps 等人（2014）从神经一侧说了兼容的话：偶然情绪会渗进主观价值；对选项的情绪反应也会进入价值计算；改情绪可以改选择。

因此，人物描述里的「情绪稳定性」特质（[第二篇](02-personality-and-experience.md)）和「他现在焦虑」不是重复信息。特质是跨时间的相对位置。现在的情绪是这一次估值的调制。只知道他通常不易焦虑，不知道他这次是不是刚被扣过一笔不明费用。

## 人与情境：假的二选一

Funder（2006）把人、情境、行为称为人格三角。每个元素都要用另外两个来理解。一个人，是他在种种真实和可能情境里的行为的总和。一种情境，可以用它倾向引出的行为、以及哪些人会这样做来描述。他针对的是人—情境之争：一方说行为由人格决定，一方说由情境决定。他认为这是虚假的二分。行为既可以因为情境的细小变化而改变，同时个体差异仍然保持。他在 2009 年的议程文章里把 Lewin 的公式写成行为是人与情境的函数，并警告不要用方差分析去裁判「人更重要还是情境更重要」。公式是概念，不是一份百分比。

Mischel 与 Shoda（1995）给出个体水平上的写法，已在第二篇介绍：稳定的是若—则签名。情境不是误差项。换一个心理特征不同的情境，同一个人的行为按可重复的方式变化。Funder 认为，把这种变化看成人格失败，是看错了人格是什么。

社会层面的证据更硬。Henrich 等人（2001，详见 [第一篇](01-biology-and-evolution.md)）发现，最后通牒博弈里的出价随群体变化，范围从赌注的 26% 到 58%，而个人层面的经济与人口学变量解释不了这些差异。市场融入和日常合作的回报才能。一个「同年龄、同财富」的人，换一个日常回报结构不同的群体，公平行为就不同。预测付费时，只写人口学、不写他周围的人如何对待试用、退款和欠费，是在重复他们已经否定的做法。

框架研究则表明，连「情境」都不能写成客观的物理描述。Tversky 与 Kahneman（1981）的效应来自表述。同一笔钱，说成损失还是说成成本，问题已经不同。预测者若只记录「价格是 30 元」，没有记录这 30 元在他面前以什么句子出现、旁边还有什么选项，情境就写丢了一半。

## 他告诉你的理由，多半不是过程

Nisbett 与 Wilson（1977）综述的证据是：人对高阶认知过程往往没有直接的内省通道。人可以没注意到一个其实影响了反应的刺激，可以没注意到反应本身，也可以知道刺激和反应都存在，却不知道前者影响了后者。当人报告「我为什么这样判断」时，报告通常来自事先就有的、听起来合理的因果理论，而不是来自对过程的观察。当那个刺激既显眼又像是合理原因时，报告会碰巧正确；否则就错。一个特别有力的结果是：没有经历实验、只读了描述的旁观者，对「什么影响了行为」的预测，和真正参加者的错误报告很像。人是在用共享的常识理论填空。

这对学习预测的人是一条方法限制。问「你为什么会付钱」，得到的是他的常识理论：因为有用、因为便宜、因为信任这个牌子。这些理由有时重叠于真正起作用的因素，尤其当因素显眼又合理。它们系统性地漏掉不显眼的因素：其他人在不在场、句子是增益框架还是损失框架、决定之前的心情。Nisbett 与 Wilson 甚至写到，请被试报告评价、选择或行为的影响因素，除了用来研究口头解释本身，可能没有多少价值。这是 1977 年的强结论。后来的研究对内省的范围有更细的讨论，但本文没有打开那些修正，所以这里只把限制留在他们证据所及的地方：不要把事后理由当成决策过程的记录。身份叙事（第二篇）仍然可以是原因的一部分；当事人对叙事的声明，需要别的行为来核对，不能自证。

棉花糖实验的重复，是人与情境被写成性格的一个实例。Watts、Duncan 与 Quan（2018）表明，等待时间与后来学业成就的关联，在控制家庭背景、早期认知和家庭环境后大幅减弱（数字和样本限制见 [第二篇](02-personality-and-experience.md)）。一个看起来像「这个孩子性格能延迟」的行为，携带着情境。预测若只抽取性格标签，会把当时的环境再预测一次，还以为预测的是人。

## 这一层如何改变一次预测

这一层往往比特质更能移动一次具体的用或不用、付或不付。条件是：框架明确、情绪和认知评估不一致、社会回报就在眼前、当事人没有余地做工作记忆负担重的覆盖。

预测因此要带上题目，而不只是人。参照点是什么，句子把结果编成收益还是损失，哪些共同结构被孤立效应丢掉了。要带上当下情绪，并允许它压过一张冷静的功能比较表。要带上群体里这类交换通常怎么结算，而不是只带年龄和收入。要判断这次环境有没有有效线索和反馈：有，则他的再认可能是技能；没有，则他的信心不是证据。

不要用偏差清单代替这些条件。启发式可能是误差，也可能是小样本里更准的忽略。双过程若写成通俗的两个系统，连 Evans 与 Stanovich 自己都不愿保卫。人与情境哪边百分比更高，不是一个有意义的冠军问题。有意义的是这个人在这种表述、这种心情、这种社会回报下的若—则。

他嘴上的理由可以记录，但应标成自我理论，而不是机制。下一篇把这些限制收成：什么能预测，什么不能，一份以准确为目标的人物描述至少要让人回答哪些问题。
