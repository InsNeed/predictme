# 第二层：人格、性格、经历与身份

[返回导读](README.md) · 上一篇：[生物机制与进化](01-biology-and-evolution.md)

第一层描述人共有的决策机器。这一层问机器上哪些差异比较稳定，稳定的究竟是什么，以及生活经历和「我是怎样的人」怎样改写一次选择。Predict Me 要预测的是一个具体的人。人格是这个具体性的一部分，但只是一部分。把它当成命运，或者当成可以忽略的噪声，都会把预测做坏。

## 三个词，不要并成一个分数

汉语里「人格」和「性格」经常互换。这套材料把它们分开，以免把日常印象写成科学维度。

人格，在这里指人格心理学试图测量的整个人。McAdams 与 Pals（2006）把这门科学收成五条原则，他们称之为 integrative science 的 “new Big Five”，不是大五人格的五个因素。一个人是：在人类共同的进化设计之上的独特变异；这种变异表现为发展中的特质模式；加上特征性适应；加上自我定义的人生叙事；并且复杂地坐落在文化与社会情境里。五条都要在，才是他们所说的整个人。进化设计是 [第一篇](01-biology-and-evolution.md) 的背景，文化情境主要在 [第三篇](03-cognition-emotion-situation.md) 展开。本篇重点是中间三条：特质、特征性适应、人生叙事。

性格，按日常汉语，指一个人相对稳定的行事风格，常常带评价：要强、毛躁、靠得住、爱面子。科学文献里没有一个与大五人格平行、又被独立验证过的因子就叫「性格」。日常性格通常是混合物。拆开之后，一部分是特质（他在尽责性上相对别人的位置），一部分是特征性适应（他目前的目标、策略、价值观、对某类情境的解释习惯），一部分是叙事（他用什么故事说明自己是谁）。预测时如果只留一个「性格：谨慎」，这三样会糊成一句无法检验的话。

身份，在 McAdams 与 Pals 的框架里，主要指自我定义的人生叙事：人在文化里为了把生活弄得可理解，而构造的故事。它不是第二套性格测验。一个行动可以很方便，同时在叙事上不可接受，因为它会把当事人写成他拒绝成为的那种人。

## 特质结构：五因素，以及为什么有人坚持要六个

二十世纪末，很多人格研究者达成一个有限度的共识：人格描述可以大致收成五个宽维度。Ashton 与 Lee（2007）回顾了这条路线。英语词汇研究里反复出现的五个因素，后来被称为大五人格：外向性（健谈、外向，相对于安静、害羞）、宜人性（温和、有同情心，相对于严厉、冷淡）、尽责性（有条理、有纪律，相对于邋遢、懒散）、情绪稳定性（放松，相对于情绪化、焦虑），以及智力/想象（有智识、有想象力，相对于浅薄）。问卷传统里的五因素模型，尤其 Costa 与 McCrae（1992）的 NEO 系列，和这个词汇结构很接近，但有一处他们特别指出的差别：五因素模型的「开放性」不含智力能力，而词汇上的智力/想象因子包含。

Ashton 与 Lee 认为这个「有且仅有五个」的共识过早。他们综述多种语言的词汇研究，主张六个因子比五个更经常被重复出来。HEXACO 的六个名字是：诚实—谦逊、情绪性、外向性、宜人性、尽责性、开放性。其中外向性和尽责性与五因素很接近。情绪性和宜人性则是五因素里情绪稳定性与宜人性的一种旋转：HEXACO 的宜人性更包含耐心、不愤怒，情绪性更包含情绪化和感伤，而把愤怒从「神经质」里挪走。多出来的诚实—谦逊，内容是真诚、公平、不装、不贪婪。他们认为五因素把这块吸收得很差。

这是结构之争，不是某人更科学。五因素有大量问卷研究和后果研究（下面会用到 Ozer 与 Benet-Martínez）。六因素的支持来自 Ashton 与 Lee 所综述的跨语言词汇结果，以及它能容纳五因素空间里不好放的变量。预测一个具体的人时，实用的教训不是押注五或六，而是：宽因子是摘要。Ozer 与 Benet-Martínez（2006）写得很清楚，他们用五因素来组织文献，是为了知识能够累积；针对某一个具体结果，更窄的变量往往预测更好，代价是这种累积会变弱。若决定的内容是剥削、占便宜或是否公平，诚实—谦逊是五因素摘要里容易漏掉的轴。本文没有打开证明「诚实—谦逊预测订阅付费」的研究，所以只能把它列为相关候选，不能写成已经测量过的效应。

Ashton 与 Lee 还提出，HEXACO 与理论生物学里的互惠利他、亲属利他有可解释的关系。请按 [第一篇](01-biology-and-evolution.md) 的标准读这句话：它是他们的理论解释。词汇结构跨语言出现，是经验主张；「这个维度是互惠利他的心理成分」，仍是解释，不是进化事实本身。

## 有多稳：排序稳，平均水平仍在变

稳定有两种，混在一起就会误读人格。

第一种是等级顺序一致性：同龄人之间谁更高、谁更低，过几年还像不像原来的排列。Roberts 与 DelVecchio（2000）对 152 项纵向研究、3217 个重测相关做了元分析。把时间间隔控制在 6.7 年时，特质一致性从童年的约 0.31，升到大学阶段的约 0.54，30 岁时约 0.64，然后在 50 到 70 岁之间平台在大约 0.74。间隔越长，一致性越低。气质维度不如成年人格特质稳定。这些是总体估计，不是某一个人的命运。它们说明：成年之后，用特质描述人与人的相对位置是有根据的，而且中年以后比童年更有根据；它们不说明分数不动，也不说明一次行为会被这个分数决定。

第二种是平均水平的变化：整个队列在某个特质上的均值随年龄怎么走。Roberts、Walton 与 Viechtbauer（2006）元分析了 92 个样本。社会支配（外向性的一个侧面）、尽责性和情绪稳定性上升，尤其在 20 到 40 岁。社会活力（外向性的另一个侧面）和开放性在青少年期上升，到老年下降。宜人性主要在老年才表现出变化。六个特质类别里有四个在中年和老年仍有显著变化。性别和流失对变化的影响很小；研究时间更长、队列更年轻时，看到的变化更大。

因此，「人格很稳」只在第一种意义上大致成立，而且还随年龄增加。一个照着大学时期写死的人设，用来预测四十岁的人会不会为一个工具持续付钱，即使生活史一字不改，也已经错过了均值上的典型变化：尽责性和情绪稳定性在青年成年期通常是上升的。这是平均模式。它不告诉你是哪一件生活事件造成了变化。元分析记录的是变化的形状，不是每一段传记的原因。

## 经历如何进入下一次选择

经历不是特质旁边的装饰。它是 [第一篇](01-biology-and-evolution.md) 那些学习系统的数据。

Schultz、Dayan 与 Montague（1997）的预测误差说明：结果比预期好或坏，会更新对下一步的预测。Daw、Niv 与 Dayan（2005）说明：有的行动价值被缓存成习惯，有的被按后果模型重算。一个人被自动续费伤害过，和下一个人只是「尽责性分数相同」，在订阅这件事上不是同一类当事人。前者的缓存值里有一次负的预测误差，线索（「免费试用」）可能已经变得不想要；后者可能还在用目标导向系统现算。特质分数两边都可以一样。

这是把学习框架用到付费例子上，不是一篇关于订阅产品的引用研究。本文没有打开这样的消费者研究。可以用的推论只有：领域内的学习史，不能从宽特质里推出来。要预测这个人，需要知道他在相近情境里遇到过什么结果，以及那些结果更像更新了模型，还是只留下了习惯。

特征性适应是 McAdams 与 Pals 用来装这些内容的层次：目标、策略、动机、价值观、解释风格，它们比特质更靠近具体情境，也比一次情绪更耐久。Mischel 与 Shoda（1995）从另一头到达类似的地方。他们提出认知—情感人格系统：人与人的差别，在于中介单元的易得性，以及这些单元彼此之间、它们与情境特征之间如何组织。中介单元包括编码、预期和信念、情感、目标。稳定的不只是行为的平均水平，还有跨情境的变化模式本身。他们的例子形式是：若情境 A，则她做 X；若情境 B，则她做 Y。这种若—则轮廓是人格的行为签名，不是测量误差。

用到应用上：同一个人可以在「同事都在用、不试显得落后」时安装，在「需要绑定银行卡」时放弃。两个行为不必互相取消。签名就是这对若—则。只记录「他中等外向」会把签名平均掉。

## 身份：叙事会取消一些本来划算的选项

McAdams 与 Pals 把人生叙事列为与特质不同的层次。叙事的功能是在文化里制造意义，说明自己如何成为现在的人、要走向哪里。本文没有打开一项专门测量「叙事一致性如何改变应用付费」的实验，所以不给效应量。框架本身仍有预测含义：若一个选项只是贵一点，它进入的是价值比较；若它把当事人写成他自己故事里的反派（浪费的人、跟风的人、对不起家人的人），它进入的是身份。两种拒绝看起来都是「不付钱」，机制不同，换一个框架时的反应也不同。第三篇会讲框架如何移动参照点。身份决定哪些参照点他根本不愿意采用。

当事人事后讲的故事，不能直接当成这个机制的证据。人会为选择编造合理原因。这一点的实验传统在 [第三篇](03-cognition-emotion-situation.md)（Nisbett 与 Wilson，1977）。叙事作为身份是一回事，叙事作为对认知过程的内省报告是另一回事。

## 特质能预测什么，不能预测什么

Ozer 与 Benet-Martínez（2006）的综述标题就把结论说出来了：人格能预测有后果的结果。他们按五因素组织文献，特质与个体层面的幸福、身心健康、灵性和身份有关，与同伴、家庭和浪漫关系的质量有关，也与职业选择、满意度和绩效、社区参与、犯罪活动和政治意识形态有关。这些是关联的目录，不是每个领域一个通用相关系数。他们没有说某个因素主宰生活。

McAdams 与 Pals（2006）在回顾人—情境之争时写下一句对预测更关键的话。特质分数对单次情境中的行为，往往只是中等程度的预测；他们指向 Mischel 与 Peake（1982）。特质对跨情境、跨时间汇总起来的行为趋势预测要好得多；他们指向 Epstein（1979）。本文核对的是 McAdams 与 Pals 的这段综述，没有重读 Epstein 或 Mischel 与 Peake 的原文，所以不补充那两篇里的具体相关。方向已经足够用：一次「今天会不会付款」比「这类事情上他通常守不守承诺」更难从特质读出来。

延迟满足研究是一个教训，因为通俗叙述把它说成性格预测一生的范例。Watts、Duncan 与 Quan（2018）对 Shoda、Mischel 与 Peake（1990）的著名结果做了概念性重复，样本集中于母亲没有完成大学学业的儿童。在他们的数据里，4 岁时多等一分钟，对应 15 岁时学业成就大约十分之一个标准差。这个双变量相关只有原始研究的大约一半；再控制家庭背景、早期认知能力和家庭环境之后，又大约减少三分之二。与成就有关的变异，大部分来自能不能至少等 20 秒。延迟时间与 15 岁时行为结果的关联更小，而且很少达到显著。因此，「他小时候等得住，所以他会是一个有纪律的付费用户」不是这些数据许可的预测。等待行为里混着家庭资源和早期能力。把它当成纯粹的人格晶体，是把情境写进了性格。

## 这一层如何改变一次预测

人格改变的是基线分布，不是单次硬币的正面。

成年后的特质排序相当稳，而且越到中年越稳（Roberts 与 DelVecchio，2000），所以一份人物描述里应该有他在宽维度上相对别人的位置，包括当决定涉及公平和剥削时，五因素可能漏掉的诚实—谦逊。但均值会随年龄段移动（Roberts、Walton 与 Viechtbauer，2006），大学时代的分数不能原样挪到另一个生命阶段。

特质对有后果的生活结果有预测力（Ozer 与 Benet-Martínez，2006），对一次情境里的一个动作则弱得多（McAdams 与 Pals 对既有文献的总结）。要提高对这个人的分辨率，需要特征性适应和若—则签名（Mischel 与 Shoda，1995），以及这个领域里的学习史：他预期过什么，误差如何更新了习惯。身份叙事用来判断哪些选项会因为「不像我」而退出比较，而不是用来代替他口头报告的理由。

若一份人设只有形容词，它预测的是一个类型的平均趋势，不是这个人在这个框架、这种心情、这个群体里的这一次。后三样由下一篇接管。
