# 第一层：生物机制，以及进化上的理由

[返回导读](README.md)

预测一个具体的人会不会用、会不会付钱，不能从脑干开始写他的传记。生物这一层回答的是另一个问题：选择在神经系统里要完成哪些计算，这些计算由哪些回路参与，以及哪些「人类共有的倾向」有比较扎实的进化解释。它约束预测，但不提供这个人的目标、预算和过去被什么伤害过。那些是 [人格与经历](02-personality-and-experience.md) 和 [当场起作用的认知、情绪与情境](03-cognition-emotion-situation.md) 的内容。

读这一层时，请把两件事分开。第一件是机制：价值怎么被表征，学习信号怎么更新，情绪怎么调制价值。第二件是起源故事：这个机制为什么会在自然选择里留下来。机制可以有很好的生理证据，同时起源故事仍然很弱。反过来也一样：一个进化模型在数学上成立，并不等于你已经在人脑里找到了它。

## 基于价值的选择要做哪些计算

Rangel、Camerer 与 Montague（2008）给神经经济学一个至今仍好用的骨架。他们把一次基于价值的决定拆成五类计算：把决策问题表征出来（此刻的内部状态、外部状态、可以采取的行动）；给这些行动赋值；按赋值选出一个行动；结果出现之后评估这个结果有多可取；再用这次评估去更新前面的环节，使以后的决定更好。同一篇综述强调，脑里不只有一套估值。他们区分了巴甫洛夫式、习惯式和目标导向式几类系统，并指出风险、时间和社会因素会调制估值。

这套骨架对预测的意义很具体。问「他会不会付钱」，至少要知道：他表征的是哪一个问题（试用、一次买断，还是以后每个月都扣款）；他给「现在少一笔钱」和「以后少一些麻烦」赋的是什么值；选出行动之后，使用体验会不会改写他下一次的值。只写「他喜欢高效工具」停在第一段之前。

Kable 与 Glimcher（2009）综述了人和非人灵长类的神经生理研究，认为一个大致的两段式图景正在形成：估值阶段与腹内侧前额叶以及纹状体的相关部分有关，选择阶段与外侧前额叶和顶叶有关。他们把这称为正在浮现的轮廓，不是已经定案的线路图，并明确说领域里仍有激烈争论。他们还提醒一种容易混的东西。传统经济学里的效用，常常只是「仿佛」模型：只要选择在数学上一致，就可以把当事人描述成好像先排了一张从好到坏的表，再选最好的那一项。神经科学问的是算法和实现，不只是行为上像不像。有证据表明，主观价值信号确实出现在腹内侧前额叶和纹状体，可以被看成一种共同尺度。但这不等于每一个真实的人在每一个问题上都选择一致。不一致本身是 [前景理论](03-cognition-emotion-situation.md) 的起点。

所以，「脑内有价值信号」支持的是：选择不是一串互不比较的冲动，比较时脑会把不同方面收成可比较的量。它不支持：看见某个脑区亮了，就知道这个陌生人会订阅。成像相关不是操纵，实验室里的果汁、食物和简单赌局也不是应用商店。外推是假设，要另做检验。

## 多巴胺：教学信号，还是「想要」

一个影响很广的发现是，某些多巴胺神经元编码的是奖赏预测误差，而不是奖赏本身。Schultz、Dayan 与 Montague（1997）综述了灵长类的生理实验：当奖赏比预期更好，或来得比预期更早，这些神经元的活动升高；当预期中的奖赏没有来，或来晚了，活动下降。他们的解释是，这个信号报告预测的误差，并可以用来更新对未来奖赏的预测、影响之后的选择。用白话说：系统学习的是「比我以为的更好还是更差」，不是一本静态的快乐账。

这件事直接否定一种通俗说法：多巴胺冲上来等于他感到快乐，所以他会买。预测误差可以在结果并不「更快乐」、只是比预期好一点时出现；也可以在很快乐但完全在预期之中时不出现。

另一条研究路线不同意把多巴胺的主要工作说成学习。Berridge 与 Robinson（1998）在大鼠上把伏隔核和新纹状体的多巴胺耗到很低，用味觉反应测量「喜欢」：对甜和苦的享乐反应仍在，味觉厌恶学习仍在，用非多巴胺药物提高适口性也仍在。他们的结论是，多巴胺对享乐影响和这类奖赏学习都不是必需的；它更关系到激励显著性，也就是让与奖赏有关的线索变得想要、值得去追求。他们的用语是 wanting 与 liking：想要，和喜欢，可以拆开。

Berridge（2007）把争论写得更尖锐。他认为多巴胺功能有三种竞争解释：介导「喜欢」，介导预测误差和联想学习，或者介导「想要」。他的判断是，激励显著性比另外两种更符合当时的证据；在他看来，多巴胺既不是快乐所必需的，也不是新学习所必需的，却会因果地增强线索触发的「想要」。这是与 Schultz、Dayan、Montague 传统的实质分歧，不是用词不同。撰写本文时，这个分歧没有被某一方撤销。

预测时的用法是：把四句话分开，不要合成一句「他会喜欢所以他会用」。

- 他预期这个应用比现在的办法好（预测，可以被误差改写）。
- 线索本身让他想打开它（想要，可以强于事后的喜欢）。
- 用的时候他确实感到愉快（喜欢）。
- 他已经形成了不经重新估值的习惯（下一节）。

一个人可以想要一个自己并不喜欢的东西，也可以喜欢一个自己不会动手去拿的东西。付钱更接近「想要」加上一组约束（价格、时机、是否信任扣款），不是喜欢的同义词。

## 习惯、目标，以及自控在调什么

Rangel 等人说的习惯系统与目标导向系统，在计算上被 Daw、Niv 与 Dayan（2005）说成两类强化学习控制器。一类与背外侧纹状体相连，使用缓存的价值：过去什么行动带来过奖赏，就较快地再选它，计算便宜，但世界一变就显得僵。另一类与前额叶相连，使用关于后果的模型：结果的价值变了，行动的价值可以马上重算，灵活，但费计算。他们提出，两者按各自的不确定性来分工，谁在当前更可能算得准，谁就多接管。论文自己加了一条限制：皮层和纹状体是缠在一起的，把竞争说成「皮层对纹状体」是为了建模而做的简化；更贴切的说法可能是不同的皮质—纹状体环路之间的竞争。

这对「会不会继续用」很重要。第一次安装，常常更依赖目标导向的重算：这个应用能不能解决他刚才那个问题。用过许多次之后，打开它可能只是缓存下来的习惯，即使他已经说不清值不值。一个人停用，也可能是模型更新了（他发现后果变了），而不是人格变了。

自控的生理研究进一步说明，长期目标和眼前诱惑不一定是两个价值中枢在打架。Hare、Camerer 与 Rangel（2009）让正在节食的人在扫描仪里做真实的食物选择。腹内侧前额叶的活动与目标价值相关，不论当事人有没有用出自控。能自控的人，这个信号同时纳入了味道和健康；不能自控的人，它主要反映味道。背外侧前额叶在当事人行使自控时活动增强，并与腹内侧前额叶的活动相关。作者的解释是：共同的价值信号仍在腹内侧前额叶，自控是背外侧前额叶对这个信号的调制，而不是背外侧前额叶自己另算一套价值。他们把这个结果放进当时的争论里：有的理论认为短视系统和长远系统各算各的价值；他们的数据更支持「一个价值信号被调节」。

因此，不能把自控写成一种与选择无关的意志力库存。同样的食物，健康目标有没有被写进价值，选择就不同。换到付钱：一个「节俭」的人，在价值信号只反映眼前方便时会订阅，在价格和长期成本被写进同一个信号时会拒绝。你要预测的是这次有没有发生这种调制，而不只是他是不是一个有自控的人。目标从哪来，见 [第二篇](02-personality-and-experience.md)。

## 情绪回路调制价值，而不是与理性对打

通俗图景常是两套系统：情绪一套，理性一套，决策是它们拔河。Phelps、Lempert 与 Sokol-Hessner（2014）认为，情感神经科学和神经经济学更支持调制关系，而不是这种对打。他们归纳了两条影响主观价值的途径。一条是偶然的情绪状态会带到眼下的估值和选择上，即使这情绪不是由选项引起的。另一条是对选项本身的情绪反应会进入价值计算。关系是双向的：改变情绪可以改变选择。他们强调，参与的神经回路取决于哪一种情感成分、哪一个决策变量，不能收成一条「情绪通路」。

更早，Loewenstein、Weber、Hsee 与 Welch（2001）提出「风险即感受」：关于风险选择的理论大多假定人在估计结果有多好、概率有多大，再做一种期望计算；但决定当下的情绪常常和这种认知评估不一致，而不一致时，往往是情绪在驱动行为。他们综述了 LeDoux（1996）所总结的解剖工作：感觉丘脑到杏仁核有不经过皮层的投射，恐惧反应可以快于对刺激的皮层识别。本文没有重读 LeDoux 的书，这里采用的是 Loewenstein 等人对那项工作的转述。它说明一件有限度的事：有些情感反应在时间上先于仔细辨认。它不说明杏仁核等于决策，也不说明人无法事后用理由包装自己的感受。后一件事在 [第三篇](03-cognition-emotion-situation.md) 里更清楚。

把这一节和多巴胺一节放在一起：情绪、想要、喜欢、预测误差是不同的调节量。问「他高不高兴」只碰到其中一种。

## 进化解释：哪些站住，哪些只是故事

进化问题是：为什么会有这些决策倾向，而不是这个人周三下午为什么点了付款。自然选择解释的是，在过去的环境里，拥有某种可遗传变异的个体平均留下了更多后代。它不自动解释某一个现代选择。

比较扎实的一类工作给出形式条件，而不是轶事。Hamilton（1964）提出内含适合度：一个影响亲戚的行为，是否被选择青睐，取决于对行动者自身适合度的影响，加上对亲戚的影响再按亲缘关系加权。在他的模型世界里——行为严格由基因型决定——没有谁会为了救一个任意的人而牺牲自己的生命，但当因此能救下的近亲足够多时，这种牺牲可以被选择保留。他给出的经典数量关系是：多于两个兄弟，或四个半同胞，或八个嫡堂。必须连同限定一起读。这是模型里的阈值，不是对人类英雄行为的田野测量，也不是「人只帮助亲人」的经验定律。它说明的是：指向亲属的利他，可以有一个不依赖道德动机的种群遗传学理由。

Trivers（1971）处理非亲属之间的利他。互惠利他要演化，需要时间差：帮助的回报不能是即时的，同时又必须有足够的保证，使作弊者最终被选择淘汰。他强调这些条件是特化的，不是任何看起来像合作的行为都符合。他讨论了清洁共生、鸟类报警和人类互惠，并认为人类是记录较充分的例子。这仍然是一个理论模型加上对若干行为的功能解释，不是对「公平模块」的发现。

人类实验表明，合作与公平的行为内容随群体的经济生活而变，并不是一个全球相同的输出。Henrich、Boyd、Bowles、Camerer、Fehr、Gintis 与 McElreath（2001）在小规模社会中做最后通牒等博弈。论文题目写的是 15 个社会。完全自利的教科书预测是：提议者给出最小的正数，回应者接受。这个预测在他们研究的社会里都不成立。最后通牒博弈的平均出价从赌注的 26% 到 58%；他们引用的工业化社会学生样本，平均出价通常接近 44%（Roth 等，1991，转引自该文）。他们总结：群体差异大于以往跨文化研究；市场融入程度越高、日常生活中合作的回报越高，实验中的合作水平越高；个人层面的经济与人口学变量，无论在群体内还是群体间，都不能解释这些行为；实验行为大体上和这些社会的日常经济模式一致。表里有的群体人数不多，所以不值得把某一个百分比背下来。值得留下的是结构：公平出价不是物种的一个常数，个体的年龄或财富也没有在这项研究里压过群体的日常回报结构。

## 把推测的进化心理学分开

Gould 与 Lewontin（1979）批评适应主义纲领：把生物拆成一个个「性状」，再为每个性状单独编一个适应故事；只用各种需求之间的权衡来解释不完美；把当前的用途当成起源的原因；用合理性代替证据。他们用的比喻是威尼斯圣马可教堂的拱肩：拱肩在建筑上有用，但它们是拱顶结构的几何后果，不是为了在上面作画而被单独选择出来的。当前有用，说明不了当初为什么出现。

这条批评对决策研究是操作规则。下面这类句子默认不采用，除非另有历史、比较或实验证据，而不只是事后合理性：

- 「人会为应用付钱，是因为更新世的地位竞争。」
- 「损失厌恶是为了在草原上活下来，所以他不会订阅。」
- 「女性或男性更不愿为某类产品付钱，因为古代的择偶策略。」

这些句子把一个现代行为切成性状，再配上一个无法证伪的过去环境。Hamilton 和 Trivers 的模型不是这种写法：它们写出成本、收益、亲缘或回报保证，并承认条件狭窄。Henrich 等人的数据则直接反对「全世界同一套公平反应」。

人格结构与互惠、亲属利他的理论联系，放在 [第二篇](02-personality-and-experience.md) 的 HEXACO 模型里讨论。那里会标明：词汇研究重复出一个诚实—谦逊维度，是经验发现；把它解释成互惠利他的心理成分，是理论，不是这一层已经证明的进化事实。

## 这一层如何改变一次预测

生物机制改变的是预测的单元，不是给每个人填一个脑类型。

一次「会不会用、会不会付钱」，要分开预期、想要、喜欢、习惯和目标导向的重算。五者可以指向不同的行为。习惯可以在他已经不喜欢之后仍把他带回应用；一次坏于预期的体验可以改写下一步，即使特质没变。自控不是额外的人格分数，而是长期考虑有没有进入同一次估值。

情绪是估值的调制，包括与这件事无关的心情。预测若假定一个永远冷静、只比较功能列表的当事人，就会在情绪和认知评估分叉时失败。

进化层禁止两件过头的事。一是用物种故事代替这个人的学习史。二是假定公平、损失或合作有一个全球默认值。群体日常生活里合作是否得到回报，可以大过年龄和财富（Henrich 等，2001）。个体差异仍然存在，但它们从下一层才开始被认真测量。
